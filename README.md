# Bamako Drive

Jeu de conduite dans la ville de Bamako (three.js) : circulation, feux, piétons, jour / soir / nuit, radio malienne, exploration 3D, jouable sur ordinateur et smartphone.

- **Jouer** : ouvrir la page GitHub Pages du dépôt (dossier `docs/`, version construite du jeu).
- **Lancer en local** : `npm install` puis `node server.js` (ou `lancer_jeu.bat` sur Windows).
- **Reconstruire la version en ligne** : `npm run build` puis copier `dist/` dans `docs/`.
- Détails : voir `LISEZMOI.txt`.
