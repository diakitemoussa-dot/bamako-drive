# Bambara des clients — à faire relire

Traduction écrite **sans locuteur natif** : chaque ligne est à vérifier (sens, naturel, orthographe, tons).
Pour corriger : modifier la ligne dans `js/missions/bambara.js` (tableau `E` pour les phrases, `P` pour les phrases à trous), puis relancer ce script.

La colonne « Lue par la voix » est la même phrase écrite pour que la voix française la prononce (≈ approximation).
